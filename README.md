# Street Lighting Management System (North Makkah Sub-Municipalities)

A web-based asset and maintenance management platform designed for street lighting infrastructure, supporting QR code generation for poles, technician logs, and administrative dashboards.

## Features
- Admin dashboard for managing poles and viewing maintenance reports.
- Dynamic QR code generation linked to individual pole URLs.
- Technician mobile interface for recording maintenance tasks.
- Excel file import/export for bulk asset management.
